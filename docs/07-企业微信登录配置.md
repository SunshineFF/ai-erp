# 企业微信登录配置

系统支持两种登录方式：

- 普通浏览器跳转企业微信扫码登录。
- 企业微信内置浏览器自动发起 `snsapi_base` 静默授权。

## 企业微信后台配置

1. 创建或选择一个企业内部自建应用，记录企业 ID、应用 AgentId 和应用 Secret。
2. 将 ERP Web 所在域名配置为应用的可信域名。
3. 将 API 回调地址配置为应用允许的 OAuth/扫码回调地址，例如 `https://erp.example.com/api/auth/wecom/callback`。
4. 回调地址必须与 `WECOM_REDIRECT_URI` 完全一致；生产环境应使用 HTTPS。

## API 环境变量

```env
WECOM_CORP_ID="wwxxxxxxxxxxxxxxxx"
WECOM_AGENT_ID="1000002"
WECOM_SECRET="应用 Secret"
WECOM_REDIRECT_URI="https://erp.example.com/api/auth/wecom/callback"
WECOM_SCOPE="snsapi_base"
WEB_ORIGIN="https://erp.example.com"
```

企业微信登录未配置时，账号密码登录仍可使用。

## 成员绑定

进入“用户与权限”，编辑 ERP 用户，在“企业微信成员 ID”中填写企业微信通讯录成员的 UserId。系统只允许已绑定且启用的 ERP 用户登录，不会自动创建账号或授予角色。

同一个企业微信成员 ID 只能绑定一个 ERP 用户。清空该字段即可解除绑定。
