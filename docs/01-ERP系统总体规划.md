# 新时代 ERP 系统总体规划

## 1. 文档目的

本文定义面向橡胶件制造企业的一期 ERP 产品蓝图。系统以进销存为交易主线，以橡胶配方/BOM、原材料、半成品、成品、批次库存和成本为统一数据基础，并提供可审计、可配置、可扩展的业务能力。

本文只定义产品、业务和架构方向，不包含技术实现代码。后续设计、原型、数据字典与开发任务均以本文为上位依据。

## 2. 产品定位

### 2.1 目标客户

- 首个落地对象为橡胶件制造企业，覆盖配方混炼、半成品流转、成品生产和销售。
- 需要同时处理按订单生产与按库存生产的制造企业。
- 需要从成品批次反向追溯到生产订单、原材料批次和供应商来源的运营团队。

### 2.2 产品原则

- **一份业务事实**：同一物料、库存数量、批次和单据状态在全系统有唯一来源。
- **单据驱动**：业务变化均通过可追溯单据发生，而非直接修改余额。
- **版本可追溯**：配方/BOM、价格和基础资料在变更后保留历史版本。
- **实时可见**：库存、可用量、订单履约、生产进度和经营预警按权限实时呈现。
- **智能辅助，人可决策**：AI 用于识别、建议、问答和异常预警；涉及库存、价格、审批、结账的动作必须由授权人员确认。
- **移动优先的执行体验**：仓库和生产现场可通过扫码、平板或移动端完成高频操作。

## 3. 业务范围与分期

### 3.1 一期（MVP）范围

| 领域 | 一期能力 |
| --- | --- |
| 基础资料 | 单公司、单仓库/多库位、用户、角色、客户、供应商、计量单位、物料、价格表、币种、汇率、税率 |
| 采购 | 采购申请、采购订单、收货入库、采购退货、应付状态查询 |
| 销售 | 报价、销售订单、发货出库、销售退货、应收状态查询 |
| 库存 | 入出库、调拨、盘点、库存冻结、全物料批次/效期、可用库存、库存流水 |
| 生产 | 保密配方/BOM、按订单/按库存生产、生产订单、领料、完工入库、退料、报废/损耗登记 |
| 成本 | 移动加权平均成本、采购成本、生产完工成本、库存金额查询 |
| 经营台 | 待办、库存预警、订单履约、采购交期、销售和库存概览 |
| 平台能力 | 角色与配方专属权限、附件、操作日志、图片/XLSX 解析建草稿、导入导出、消息通知、基础报表、手机端 PWA |

### 3.2 二期范围

- 需求计划（MRP）、安全库存和补货建议。
- 委外加工、工序与工艺路线、生产报工。
- 条码/RFID、PDA 离线作业、质检与不合格品处理。
- 多组织、多工厂与财务总账集成。
- 预算、费用、应收应付对账、电子发票和银行流水集成。
- 客户门户、供应商协同和开放 API。

### 3.3 三期范围

- 高级计划排程（APS）、设备与维护（EAM）、项目成本。
- AI 预测（销量、缺货、交期）、票据识别、自然语言经营分析与异常根因建议。
- 数据仓库、指标体系和自助 BI。

## 4. 组织、角色与权限

### 4.1 组织模型

第一期实际运行范围为单公司、单仓库、多库位与业务部门。数据归属公司，部门负责业务协作，库位用于库存与执行范围控制；数据模型保留租户、公司和仓库维度，为后续多组织、多仓库扩展做准备。

### 4.2 典型角色

| 角色 | 主要权限 |
| --- | --- |
| 系统管理员 | 租户配置、组织、用户、角色、审计查看 |
| 销售专员/主管 | 客户、报价、销售订单、发货、价格维护 |
| 采购专员/主管 | 供应商、采购申请、采购订单、收货确认、采购价格维护 |
| 仓库人员/主管 | 收货、发货、调拨、盘点、批次管理、库存冻结 |
| 生产计划员 | BOM、生产订单、产能和物料齐套查看 |
| 生产执行人员 | 领料、退料、完工、报废、批次记录 |
| 财务人员 | 成本核算、应收应付状态、结账、财务凭证接口 |
| 管理者 | 跨部门看板、经营报表、预警处理 |

权限应由「角色 + 数据范围 + 动作权限」组成。例如仓库员只能操作被授权库位，销售员只能查看本部门客户与订单。配方查看、维护、导出为独立权限，默认不授予仓库人员和生产执行人员。一期不启用审批流。

## 5. 核心业务对象

### 5.1 物料与成品

所有可采购、销售、生产、存储或消耗的对象均定义为物料，并由物料分类和属性区分用途。

| 物料类型 | 典型用途 | 库存管理 |
| --- | --- | --- |
| 原材料 | 生产领用 | 是 |
| 辅料/包装材料 | 生产领用或耗用 | 是 |
| 半成品 | 工序或配方中间产物 | 是 |
| 成品 | 对外销售或入库 | 是 |
| 商品 | 直接采购后销售 | 是 |
| 服务/费用 | 采购或销售项目 | 否 |

物料主数据至少包含：编码、名称、规格、分类、基础单位、辅助单位及换算率、库存单位、批次/效期规则、默认仓库、采购/销售/生产属性、成本方法、最低库存、税率、图片和附件。

### 5.2 配方与 BOM

系统统一使用 BOM（物料清单）模型，使用「配方」作为配方型生产企业的业务名称。每个 BOM 必须包含版本、生效日期、失效日期、状态和产出定义。

- 成品或半成品可拥有多个 BOM 版本；生产订单一经下达，必须锁定所用 BOM 版本。
- BOM 行记录投入物料、单位用量、损耗率、替代料组、领料仓库建议和备注。
- 支持主产品、联产品和副产品；一期先实现单一主产出，联副产品列为二期能力。
- 配方保密时，通过角色、数据范围和附件权限控制查看与导出。
- BOM 变更采用「草稿 - 待发布 - 已生效 - 已停用」状态，不允许覆盖已生效版本；一期由具备配方发布权限的角色直接发布，不经过审批流。

### 5.3 批次、效期与序列号

- 原材料、半成品、成品均强制以批次作为库存明细维度，并启用效期管理。
- 批次库存至少记录批次号、生产日期、到期日期、供应商批号、质检状态和来源单据。
- 出库策略可按先进先出（FIFO）、先到期先出（FEFO）或人工指定执行。
- 高价值或单件追溯物料可启用序列号；一期允许预留数据模型，优先实现批次管理。

## 6. 核心单据与业务流程

### 6.1 统一单据状态

业务单据采用：草稿、已提交、执行中、已完成、已关闭、已作废。库存执行单据还需要：待过账、已过账、已冲销。一期不配置审批中、已批准等审批状态。

原则：已过账单据不可直接删除或改写；错误更正通过反向/冲销单据完成，并完整保留关联关系。

### 6.2 采购到付款（P2P）

```text
采购申请 -> 采购订单 -> 收货单/采购入库单 -> 采购发票/应付确认 -> 付款（财务二期）
                         -> 采购退货单
```

- 采购订单占用预计到货量，不增加现存库存。
- 收货并过账后增加实际库存、批次库存和采购入库成本。
- 收货数量、订单数量、验收数量、退货数量必须可分别追踪。

### 6.3 销售到收款（O2C）

```text
报价单 -> 销售订单 -> 拣货/发货单 -> 销售出库单 -> 销售发票/应收确认 -> 收款（财务二期）
                    -> 销售退货单
```

- 销售订单可配置是否占用可用库存；发货出库后减少实际库存并确认库存成本。
- 支持按订单、客户、物料、批次和交期追踪履约进度。

### 6.4 生产到入库（M2I）

```text
销售预测/销售订单/安全库存 -> 生产订单 -> 领料出库 -> 生产执行 -> 完工入库
                                           -> 退料入库 / 报废单
```

- 创建生产订单时选择产出物料、数量、仓库、BOM 版本和计划日期；系统展开理论用料。
- 领料后减少原料库存；完工入库后增加成品库存。
- 实际领料、退料、损耗与理论用料之间形成差异分析。
- 一期采用按生产订单归集成本；完工时结转材料实际耗用和定义的制造费用规则。

### 6.5 库存内部作业

```text
调拨申请 -> 调拨出库 -> 调拨入库
盘点任务 -> 盘点录入 -> 盘盈/盘亏单 -> 库存调整过账
```

- 任何库存变化均生成不可篡改库存流水，记录发生时间、数量、单位成本、来源单据、操作人和业务维度。
- 可用库存 = 现存库存 - 锁定库存 - 质检冻结库存；在途库存独立展示。

## 7. 库存与成本规则

### 7.1 库存数量模型

库存余额的最小粒度为：公司、仓库、库位、物料、批次（如启用）、单位。库存操作以「库存事务」追加方式记录，并根据事务实时或准实时汇总余额。

### 7.2 一期成本策略

- 默认使用移动加权平均法，按公司 + 物料维度维护库存单位成本。
- 采购入库：以采购价、税费和可配置的附加费用形成入库成本。
- 销售出库：按出库时库存单位成本结转销售成本。
- 生产完工：按该生产订单的实际材料耗用加可配置制造费用计算成品成本。
- 盘盈、盘亏、报废、退货、冲销均须带有成本影响与原因代码。
- 月结后禁止修改影响已结期间成本的单据；通过下一期间调整或财务反结账流程处理。

### 7.3 后续成本演进

二期再引入批次成本、先进先出、标准成本、实际成本差异、联副产品成本分摊和财务凭证自动生成。

## 9. 数据模型蓝图

### 9.1 核心实体关系

```text
客户/供应商 ---< 销售订单 / 采购订单 >--- 物料
物料 ----------< BOM头 ---< BOM明细 >--- 投入物料
仓库 ---< 库存余额 --- 物料 ---< 库存事务 >--- 业务单据
生产订单 ------< 领料/退料/完工单 >--- 物料与批次
用户 ---< 操作日志、业务单据
```

### 9.2 必备实体

| 分类 | 实体 |
| --- | --- |
| 组织与安全 | 租户、公司、部门、用户、角色、权限、数据范围、审计日志 |
| 主数据 | 物料、物料分类、计量单位、单位换算、客户、供应商、仓库、库位、价格表、税率、原因代码 |
| 配方生产 | BOM 头、BOM 明细、BOM 版本、生产订单、生产订单用料、领料单、退料单、完工单、报废单 |
| 采购销售 | 采购申请、采购订单、采购收货、采购退货、销售报价、销售订单、发货单、销售退货 |
| 库存成本 | 库存事务、库存余额、库存锁定、批次、盘点任务、盘点明细、成本期间、成本调整 |
| 平台能力 | 附件、评论、通知、编号规则、导入任务、导出任务、集成事件 |

### 9.3 全局字段约定

业务实体至少包含：唯一 ID、租户 ID、公司 ID、单据编号、状态、版本号、创建人、创建时间、更新人、更新时间、审核人、审核时间、作废原因、来源单据类型与来源单据 ID。金额使用定点小数，数量与单价分别保留可配置精度，禁止使用二进制浮点数作为财务计算依据。

## 10. 界面与交互原则

- 工作台按角色展示待办、风险与关键指标，避免把所有功能平铺给每位用户。
- 单据界面采用「抬头 + 明细行 + 附件/操作记录」统一布局，降低学习成本。
- 高并发现场操作提供扫码输入、快捷建单、默认仓库/库位、最近使用物料和批量操作。
- 库存数量、可用量、在途量、锁定量须使用明确标签，不以单一“库存”概念混淆。
- 删除、作废、冲销、提交和过账等高风险动作必须有确认、权限校验和操作记录。
- 报表支持筛选、钻取到原始单据、导出与订阅；指标必须显示统计口径与更新时间。

## 11. AI 能力边界

### 11.1 可在一期预留的智能能力

- 自然语言查询：将“本月哪些原料快缺货”转换为受权限约束的报表查询。
- 票据识别辅助：从采购单、送货单提取候选字段，由用户核对后生成草稿。
- 异常提醒：识别低于安全库存、临期、超交期、毛利异常、领料偏差等情况。
- 知识助手：基于已授权的操作手册和业务数据回答流程问题。

### 11.2 必须遵守的控制

- AI 不可绕过数据权限与库存过账规则。
- AI 生成单据只能保存为草稿或待提交状态，不可直接过账。
- 每次 AI 查询、建议与采纳动作必须记录输入来源、用户、时间和结果摘要。
- 不把配方、客户价格、个人信息等敏感数据用于未经授权的模型训练或外部传输。

## 12. 技术与架构原则（不限定具体技术栈）

- 采用模块化单体作为一期优先架构：以关系型数据库保证单据、批次库存和成本的一致性，以响应式 Web/PWA 覆盖电脑与手机端；业务稳定后再按负载和团队边界拆分服务。
- 交易类数据使用关系型数据库，保证单据、库存和成本变更的一致性；搜索、分析和文件存储使用适配的专用组件。
- 关键库存操作应具备幂等键、并发控制、事务边界和可重放事件，防止重复扫码或网络重试造成重复过账。
- 以 API 和领域事件作为模块集成边界，为财务、WMS、MES、商城和 BI 集成预留能力。
- 支持多租户隔离、细粒度授权、全链路审计、备份恢复、监控告警和数据归档。

## 13. 安全、合规与审计

- 认证一期支持账号密码，并为企业单点登录和多因素认证预留演进路径。
- 密码、密钥、令牌等敏感信息须加密存储；敏感字段展示与导出支持脱敏。
- 所有涉及价格、库存、配方、权限和结账的操作均记录不可抵赖审计日志。
- 审计日志至少包括操作人、时间、客户端、对象、操作类型、变更前后摘要与关联单据。
- 制定数据保留、备份、恢复演练和离职账号回收策略，满足当地数据与财税合规要求。

## 14. 指标与报表口径

一期应优先提供以下可钻取报表：

- 库存：现存量、可用量、库存金额、库龄、呆滞料、临期料、出入库流水。
- 销售：销售额、销量、毛利、订单交付率、客户/产品排行、退货率。
- 采购：采购金额、到货及时率、供应商交付表现、采购价格变化、未到货订单。
- 生产：计划达成率、物料齐套率、领料差异、单位产出耗料、报废率、生产订单成本。
- 经营：订单金额、应收应付状态、库存资金占用、缺货风险、待处理和异常事项。

每个指标应明确定义：统计范围、时间口径、状态过滤条件、金额是否含税、成本方法与刷新频率。

## 15. 非功能需求（一期建议目标）

| 维度 | 建议目标 |
| --- | --- |
| 可用性 | 工作时间内核心交易功能月可用性不低于 99.9% |
| 性能 | 常用列表与库存查询在正常负载下 95% 请求小于 2 秒 |
| 一致性 | 已过账库存事务与库存余额可对账；单据重复提交不得重复记账 |
| 审计 | 高风险操作 100% 记录操作日志，且可按单据追溯 |
| 恢复 | 明确 RPO/RTO，至少按日备份并定期验证恢复流程 |
| 扩展性 | 新增单据类型、审批规则、字段和报表不应修改核心库存核算规则 |

## 16. 建议的实施节奏

1. **业务蓝图与原型（2-4 周）**：确认橡胶件生产场景、单据字段、批次效期、配方权限、库存和成本口径，完成核心流程原型。
2. **MVP 开发（8-12 周）**：优先交付主数据、库存、采购、销售、保密 BOM、生产订单、文件解析、手机端和核心报表。
3. **试点上线（4-6 周）**：选择一个公司/仓库和有限物料范围，完成期初数据导入、用户培训、并行账核对和问题收集。
4. **稳定与扩展（持续）**：补充 MRP、质量、财务集成、移动作业与 AI 辅助，并按实际数据校准预警规则。

## 17. 上线验收条件

- 主数据完成编码规范、清洗、导入和抽样校验。
- 采购、销售、生产、调拨、盘点、退货等核心流程可端到端闭环。
- 库存余额可与期初数据及试运行流水对账，批次追溯可从成品追至原料来源。
- 至少一个完整结算周期的成本计算可复核，差异有明确处理流程。
- 权限、配方保密、操作日志和备份恢复完成验收演练。
- 关键岗位完成培训，形成操作手册与异常处理机制。

## 18. 一期已确认的项目决策

| 决策项 | 一期结论 |
| --- | --- |
| 首个行业 | 橡胶件制造业，覆盖配方混炼、半成品与成品生产场景。 |
| 组织与仓库 | 单公司、单仓库；数据模型预留未来多组织、多仓库扩展能力。 |
| 币种与税率 | 多币种、多税率均纳入一期。系统应定义本位币，并保留交易币种、汇率和折算金额。 |
| 批次与效期 | 原材料、半成品、成品全部启用批次和效期管理；需支持从成品批次反查原料批次。 |
| 生产模式 | 按订单生产与按库存生产并存；生产订单须标明来源类型与关联销售订单（如有）。 |
| 配方权限 | 配方/BOM 必须保密，仅被显式授予权限的用户可查看、维护或导出；未授权用户仅可按生产指令领取物料。 |
| 成本方法 | 一期采用移动加权平均成本，可接受；批次成本、FIFO、标准成本列为后续能力。 |
| 外部系统集成 | 一期不对接财务、商城、电商、WMS、MES 或条码设备；保留开放 API 与集成事件边界。 |
| 移动端 | 一期必须支持手机端，优先覆盖扫码/录入、收发货、领退料、完工、盘点和待办查询。 |
| 生产工序 | 一期不拆分密炼、开炼、硫化等生产工序；一张生产订单以领料、退料、完工、报废完成生产闭环。 |
| 效期规则 | 收货、库内、领料与发货均按物料有效期规则提醒；默认 FEFO，临期批次允许领料和发货但提示剩余有效期，过期批次禁止领料和发货。 |
| 币种 | 本位币为人民币（CNY），一期新增美元（USD）；外币单据保存交易币种、手工维护汇率、汇率日期和本位币折算金额。 |
| 税率 | 一期提供可维护税率表，预置 13%、9%、6%、3%、0% 等常见中国税率；按单据行锁定税率与税额。 |
| 数据录入与迁移 | 支持上传图片和 XLSX 文件，解析订单、发货单、采购单和财务流水；解析结果必须由用户核对后生成草稿，不得自动过账。 |
| 角色与权限 | 一期不固化采购、销售、仓库、生产等业务角色，由管理员在系统中自建角色并配置菜单、数据范围和动作权限。 |
| 冲销 | 单据冲销权限由自建角色配置；是否允许冲销及允许时限均读取系统配置，不写死固定天数。 |
| 审批 | 一期不配置审批流。单据以提交、过账、作废/冲销等业务状态流转，并保留操作审计；审批引擎预留为后续扩展。 |

已提供期初库存、历史订单和财务流水的简约 XLSX 样例。原型阶段仍需确认：各物料分类的默认有效期和临期天数；图片解析所需的采购单、销售订单和发货单版式。
