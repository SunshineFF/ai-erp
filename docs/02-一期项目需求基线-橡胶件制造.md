# 一期项目需求基线：橡胶件制造 ERP

## 1. 文档定位

本文将《01-ERP系统总体规划》收敛为一期可交付范围，用于需求评审、原型设计、开发拆分与上线验收。

一期边界：单公司、单仓库、多币种、多税率；无审批流、无外部系统对接；支持网页端和手机端；原材料、半成品、成品均强制批次与效期管理。

## 2. 橡胶件制造业务模型

### 2.1 物料分层

| 层级 | 示例 | 一期要求 |
| --- | --- | --- |
| 原材料 | 生胶、炭黑、白炭黑、硫化剂、促进剂、色母、油料 | 采购入库、供应商批号、效期、批次成本、质检状态 |
| 包装/辅料 | 包装袋、标签、隔离剂 | 批次、效期、生产领用与库存预警 |
| 胶料半成品 | 混炼胶、预成型胶坯 | 配方产出、生产批次、效期、可再次领用 |
| 成品 | 密封圈、减震垫、异形橡胶件 | 生产完工、成品批次、效期、销售出库、追溯 |
| 外购商品/服务 | 外协件、运输、加工服务 | 商品库存或费用登记；服务不计库存 |

### 2.2 配方与保密规则

- 配方/BOM 以版本管理，包含产出物料、标准产量、投料明细、单位用量、理论损耗率、生效区间和版本状态。
- 生产订单采用“抬头 + 多产出物料行”；每个产出物料行分别锁定一个 BOM 版本，后续修改配方不影响已下达订单与历史批次。
- 配方查看、维护、导出分别授权。未授权人员不可查看配方行、配方附件、理论用量和配方成本。
- 生产操作员仅接收生产任务和按批次领料指令；其页面不展示完整配方比例。
- 配方访问、导出、版本变更、作废均写入审计日志。

### 2.3 追溯目标

系统必须支持以下双向追溯：

```text
成品批次 -> 完工单 -> 生产订单 -> 领料批次 -> 原材料采购入库/供应商批号
原材料批次 -> 被领用的生产订单 -> 半成品/成品批次 -> 发货单 -> 客户
```

若某批原料出现质量问题，用户可定位受影响的半成品、成品、库存数量和已发货客户；该能力是一期开工验收条件。

### 3.2 明确不在一期

- 审批流、加签、委托和金额审批。
- 外部财务、商城、电商、WMS、MES、设备和硬件扫码枪集成。
- MRP、APS、委外加工、工序级报工、质量检验流程、联副产品成本分摊。
- 总账、自动凭证、收付款核销和电子发票。
- 原生 iOS/Android App。第一期采用响应式 Web/PWA，以降低交付与维护成本。

## 4. 核心业务流程与规则

### 4.1 采购与入库

```text
采购单 -> 到货登记 -> 采购入库（批次、效期、供应商批号） -> 库存可用
                         -> 采购退货
```

- 采购单可用手工创建，或由图片/XLSX 解析后生成草稿。
- 入库必须填写或生成内部批次号、供应商批号、生产日期、到期日期和实际数量；缺少批次或效期不得过账。
- 采购价格按交易币种录入，系统保存本位币折算金额、汇率和汇率日期。
- 解析出的字段必须展示置信度/待确认标记，用户确认后方能提交；解析不改变库存。

### 4.2 销售与发货

```text
销售订单 -> 库存预留（可配置） -> 发货单 -> 销售出库 -> 库存扣减
                              -> 销售退货 -> 入库批次恢复/新建
```

- 销售订单采用“抬头 + 多物料明细行”，记录下单日期（默认当天）、预计出库日期、实际出库日期、客户、币种、税率、价格与备注。
- 销售订单点击“开始生产”后，一个销售订单生成一张多产出生产订单；可生产的销售明细各自形成产出排产行并按其有效 BOM 展开理论用料。
- 发货时必须选择成品批次；系统按可用库存校验，不允许超发。
- 销售退货必须记录原发货单和退回批次；无法确认来源时建立隔离批次并标记待处理。

### 4.3 生产：按订单与按库存并行

```text
销售订单 -----> 生产订单（按订单） -----> 领料 -> 生产 -> 完工入库
安全库存/计划 -> 生产订单（按库存） -----> 领料 -> 生产 -> 完工入库
```

- 一期生产订单不拆分密炼、开炼、硫化等工序，不建立工艺路线、工序任务或工序报工。生产订单以“领料至完工”的单一生产闭环核算。
- 生产订单必须记录生产类型、计划日期、目标库位，以及一行或多行产出物料、计划数量、单位和 BOM 版本；销售订单触发时按销售明细生成多物料排产。
- 按订单生产记录关联销售订单及行项目；按库存生产记录补货原因或安全库存触发信息。
- 下达时展开理论投料；领料按实际批次记录，允许在授权范围内超领或少领，并要求填写差异原因。
- 完工入库形成新的半成品或成品批次，记录实际产出、生产日期、按产出物料规则计算的到期日期、报废量和生产订单。
- 领料、退料、完工、报废均产生库存事务，已过账事务只能冲销。

### 4.4 库存与效期

- 所有存货物料强制批次和效期。库存余额维度为仓库、库位、物料、批次、单位。
- 收货时优先录入供应商标签的生产日期和到期日期；若供应商未提供到期日期，则系统按物料有效期规则计算并要求操作员确认。
- 出库默认使用先到期先出（FEFO）；允许具备批次选择权限的用户手动调整，但必须保留操作记录。
- 库存状态至少包括可用、锁定、冻结、隔离、已过期；只有可用库存可被生产领料和销售出库。
- 系统在收货、库内、领料和发货环节按物料的有效期规则提醒。工作台展示临期、过期、低库存、负库存风险和被锁定批次；临期批次允许领料和发货，但必须显示剩余有效期；过期批次禁止领料和销售出库。
- 单仓库不意味着单库位。建议一期建立原料区、待检/隔离区、生产暂存区、成品区、退货区，支持实物流转与账实核对。

### 4.5 币种、汇率与税率

- 公司本位币固定为人民币（CNY）。一期启用人民币和美元（USD），其他币种不开放新增。
- 采购、销售单据可选择 CNY 或 USD。USD 单据须录入/选择对人民币汇率与汇率日期，提交后锁定；系统同时保存交易币金额和人民币折算金额。
- 汇率一期由有权限的管理员手工维护，支持按日期查询历史汇率；不接入外部汇率服务。
- 税率以可维护税率表管理，预置 13%、9%、6%、3%、0%。物料可维护默认税率，单据行允许在授权范围内调整并锁定历史税率。
- 单据行计算规则为：未税金额、税率、税额、含税金额四项同时保存；税额按配置的金额精度和舍入规则计算，单据合计允许因行级舍入存在可控尾差。

### 4.6 文件解析与财务流水

| 输入 | 支持格式 | 目标草稿 | 一期处理原则 |
| --- | --- | --- | --- |
| 采购单/送货单 | 图片、PDF 图片页、XLSX | 采购单或采购入库草稿 | 提取供应商、日期、物料、数量、价格、税率；必须人工匹配物料与批次信息 |
| 销售订单/发货单 | 图片、PDF 图片页、XLSX | 销售订单或发货草稿 | 提取客户、产品、数量、价格、交期；发货仍须人工选择库存批次 |
| 财务流水 | XLSX、图片 | 财务流水记录 | 仅导入查询、标注与关联订单；不做自动收款核销或总账凭证 |

系统需保存原文件、解析版本、字段映射、操作者、确认结果和由其生成的草稿编号，确保可追溯。解析失败时允许下载错误行或直接进入人工录入。

## 5. 单据清单与状态

一期无审批流，采用业务状态控制。所有已过账单据不可直接修改或删除，只能创建冲销/退货/调整单。

| 单据 | 关键状态 | 库存影响 |
| --- | --- | --- |
| 采购单 | 草稿、已提交、部分收货、已完成、已关闭、已作废 | 无 |
| 采购入库单 | 草稿、待过账、已过账、已冲销 | 增加原料/辅料批次库存 |
| 销售订单 | 草稿、已提交、部分发货、已完成、已关闭、已作废 | 可选锁定库存 |
| 销售出库单 | 草稿、待过账、已过账、已冲销 | 减少成品批次库存 |
| 生产订单 | 草稿、已下达、执行中、已完工、已关闭、已作废 | 无，关联领料/完工单 |
| 领料/退料单 | 草稿、待过账、已过账、已冲销 | 减少/增加指定原料批次库存 |
| 完工入库单 | 草稿、待过账、已过账、已冲销 | 增加半成品/成品批次库存 |
| 调拨单 | 草稿、待过账、已过账、已冲销 | 库位间转移，不改变总量 |
| 盘点/调整单 | 草稿、待过账、已过账、已冲销 | 盘盈、盘亏或状态调整 |

## 6. 移动端范围

移动端以浏览器/PWA 交付，支持 Android 和 iPhone 主流浏览器。应适配摄像头扫码和图片上传；离线作业不进入一期。

| 场景 | 移动端操作 |
| --- | --- |
| 仓库收货 | 扫描/录入物料与批次，拍照上传送货单，录入数量与效期，提交入库草稿 |
| 生产领料 | 查看任务指令，扫描原料批次，录入实领数量和差异原因 |
| 完工入库 | 扫描生产订单，录入产出、损耗、生产日期和成品批次 |
| 发货 | 查看发货任务，扫描成品批次，校验数量并提交出库草稿 |
| 盘点 | 扫描物料/批次，录入实盘数量，查看差异 |
| 查询 | 我的待办、库存、批次效期、生产订单进度、异常预警 |

## 7. 数据与权限要求

### 7.1 关键主数据字段

| 对象 | 一期关键字段 |
| --- | --- |
| 物料 | 编码、名称、规格、分类、可选图片、单位、换算率、批次必填、有效期计算方式、有效期天数、临期预警天数、最小库存、默认库位、采购/生产/销售属性、默认税率 |
| 批次 | 内部批次号、供应商批号、物料、生产日期、到期日期、库存状态、来源单据、供应商、质检备注 |
| BOM | 成品/半成品、版本、状态、生效区间、标准产量、投入物料、用量、损耗率、保密级别 |
| 币种/汇率 | 币种代码、币种名称、本位币标记、汇率日期、对人民币汇率、维护人、状态 |
| 税率表 | 税率代码、税率、名称、适用范围、启用状态、生效日期、失效日期 |
| 交易单据 | 单据编号、往来单位、交易币种、汇率、汇率日期、未税金额、税率、税额、含税金额、人民币折算金额、状态、来源文件、操作记录 |

### 7.2 可配置角色与权限

- 一期不固化采购、销售、仓库、生产等业务角色。管理员可在系统中创建角色，将菜单、数据范围和动作权限组合后分配给用户。
- 配方查看、配方维护、配方导出必须为三项独立权限；库存过账、库存冲销、盘点调整、报废也必须为独立动作权限。
- 系统默认只提供“系统管理员”和若干可复制的业务角色模板；模板不是权限边界，实际权限以管理员配置的角色为准。
- 文件上传者不等于单据过账者；解析结果只能产生草稿。
- 所有访问配方、导出数据、过账、冲销和删除附件的行为写入审计日志。

## 8. 一期报表与预警

- 实时库存表：按物料、批次、库位、状态、效期查看数量和金额。
- 批次追溯报告：支持成品批次正向/反向追溯到采购、生产、销售单据。
- 销售履约：销售订单完成率、未发货、逾期订单、按客户/产品统计。
- 采购到货：未到货、到货差异、供应商价格与交期记录。
- 生产耗料：理论/实际领料、损耗率、产出率、生产订单材料成本。
- 异常预警：低库存、临期、过期、负库存风险、生产领料偏差、解析待确认。

## 9. 验收标准

1. 使用一张采购单、两种原材料批次和一张销售订单，可完成从采购入库到生产领料、完工入库、发货出库的完整闭环。
2. 任一成品批次可在一分钟内追溯到生产订单、所领原材料批次、采购入库单与供应商批号。
3. 原材料、半成品、成品在未填写批次或效期时均无法过账。
4. 未授权用户无法从任意页面、导出、接口或附件中看到配方明细；授权操作留有审计记录。
5. 同一业务可由网页端和手机端完成核心仓库/生产操作，移动端不发生布局遮挡或关键流程缺失。
6. 图片/XLSX 解析只生成可编辑草稿，人工确认后才可提交和过账；原始文件与解析结果可回溯。
7. 多币种采购/销售单据正确保存交易金额、本位币金额、税额、汇率和换算日期。
8. 过账后的库存余额、库存流水和移动加权成本可对账；错误单据可通过冲销恢复账实一致。

## 10. 一期默认业务规则

### 10.1 生产订单

生产订单是一张不拆工序的生产单据。它可以产出半成品或成品，依次完成下达、领料/退料、完工入库、报废登记和关闭。实际投料与 BOM 理论投料的差异按物料、批次和原因代码留痕；一期不计算工序人工、设备工时和制造费用分摊，生产完工成本以实际材料耗用为主。

### 10.2 有效期与物流作业提醒

有效期规则按物料维护，可配置为“供应商标签优先，缺失时按生产日期/入库日期加有效期天数计算”。每个物料还配置临期预警天数。

| 环节 | 默认规则 |
| --- | --- |
| 收货入库 | 展示并校验生产日期、到期日期；日期不合理或已过期时禁止过账。 |
| 库内管理 | 工作台每日汇总临期和过期批次；临期不自动冻结，过期自动转为不可用。 |
| 生产领料 | 默认按 FEFO 推荐批次；临期批次提示剩余天数但允许领料，过期批次禁止领料。 |
| 销售发货 | 默认按 FEFO 推荐成品批次；临期批次提示但允许发货，过期批次禁止发货。 |
| 退货/隔离 | 无法确认效期或来源的批次进入隔离状态，不参与可用库存。 |

### 10.3 币种与税率

| 配置项 | 一期默认 |
| --- | --- |
| 本位币 | 人民币（CNY） |
| 外币 | 美元（USD） |
| 汇率 | 管理员手工维护 USD/CNY 日汇率；单据提交时锁定汇率与汇率日期。 |
| 税率表 | 预置 13%、9%、6%、3%、0%；管理员可新增、停用或设定生效期。 |
| 金额精度 | 金额保留 2 位小数，数量和单价精度可按物料/系统配置。 |
| 价格口径 | 采购、销售支持含税价与未税价录入，由系统计算另一口径与税额。 |

### 10.4 冲销与角色控制

- 单据的创建、提交、过账、冲销、盘点调整和报废不绑定固定业务角色，均由系统内自建角色的动作权限决定。
- 每种可冲销单据读取系统参数 `冲销允许时限（天）`。系统以原单据过账日期与当前日期计算，超过时限不允许冲销，并提示联系管理员调整配置或走期末调整流程。
- 系统参数由拥有“系统参数维护”权限的用户设置；参数修改本身写入审计日志，并从修改后创建的操作即时生效，不追溯改变既有审计记录。
- 财务已结账期间（后续启用财务模块时）禁止直接冲销；一期虽不启用总账，也应预留该校验开关。
