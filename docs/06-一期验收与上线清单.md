# 一期验收与上线清单

更新日期：2026-08-10

## 1. 自动化验证

- `npm test`：金额税额和移动加权平均成本领域测试。
- `npm run test:smoke`：真实 PostgreSQL 上的登录、权限、工作台、报表、XLSX 解析与私有文件访问验证。
- `npm run build`：API 和 Web 生产构建。
- `npm run db:migrate`：正式 Prisma 迁移部署。

## 2. 业务验收数据

在隔离验收库准备一张采购单、两种原料批次、一张含成品的销售订单及对应 BOM，依次验收：

1. 采购确认并分批收货，检查批次、效期、供应商批号、库存流水和移动平均成本。
2. 销售订单开始生产，下达生产单，按批次领料并登记差异原因。
3. 完工生成成品批次，检查实际材料成本和批次谱系。
4. 按成品批次发货，验证过期批次和超发被拒绝。
5. 从成品批次追溯到生产单、原料批次、采购来源和供应商批号。
6. 执行销售退货、采购退货、调拨、盘点、报废和库存冲销，核对余额、流水和成本记录。
7. 重复提交同一 `Idempotency-Key`，确认库存不重复变化。

## 3. 上线门禁

- 更换默认管理员密码和 `JWT_SECRET`，启用 HTTPS。
- 备份数据库和私有文件目录，完成一次恢复演练。
- 确认 `inventory.reversal_window_days` 与财务期间开关。
- 按岗位创建角色，只授予必要的配方、库存、生产、销售和导入权限。
- 图片 OCR 未接入时，明确使用人工复核流程，禁止把图片任务直接过账。
- 完成桌面与主流手机浏览器的关键作业回归。

## 4. 已知边界

- 一期不包含总账、自动核销、工序级报工、质检流、MRP/APS 或原生移动应用。
- 图片已私有保存并生成待复核任务；字段自动识别需接入正式 OCR 服务。
- 多仓、部门级数据范围和完整月结流程保留为后续扩展。
