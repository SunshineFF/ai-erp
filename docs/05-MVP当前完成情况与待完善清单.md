# MVP 当前完成情况与待完善清单

更新日期：2026-08-10

## 1. 文档用途

本文记录当前代码已经实现的能力、部分实现能力和后续开发优先级。需求范围仍以《一期项目需求基线：橡胶件制造 ERP》为准；本文不把规划项等同于已交付项。

## 2. 当前已完成

| 领域 | 已完成能力 |
| --- | --- |
| 登录与权限 | JWT 登录；用户、角色、权限维护；系统管理员全权限；业务动作使用权限代码保护。 |
| 物料主数据 | 物料新增、编辑、物理删除及引用冲突提示；物料类型、分类、单位、默认税率、有效期和临期提醒；可选 JPG/PNG/WebP/GIF 图片上传及列表缩略图。 |
| 基础设置 | 独立“设置”菜单；物料分类、计量单位、税率、货币的查询、新增、编辑和停用；CNY 为默认本位币，预置 USD。 |
| 财务基础 | 现金流水（日期、收入/支出、金额、币种、描述）；单次费用报销（日期、费用类型、金额、币种、描述）。 |
| 账单 | 采购订单生成供应商应付账单，销售订单生成客户应收账单；账单保存来源单据并防止重复生成。 |
| 往来单位 | 供应商、客户新增、编辑、物理删除及引用冲突提示；默认交易币种。 |
| 采购订单 | 抬头 + 多物料明细；列表可查看物料明细和勾选批量生成供应商对账单；草稿确认；完成后按各明细自动建立批次、增加库存余额、写入库存流水并更新收货数量。 |
| 销售订单 | 抬头 + 多物料明细；列表可查看物料明细，并勾选批量生成生产单或客户对账单；下单日期默认当天；预计出库日期、实际出库日期。 |
| BOM | BOM 版本、状态、生效日期、标准产量和投入明细的后端模型；生产下达前按有效 BOM 展开理论用料。 |
| 生产订单 | 不拆生产工序；支持手工多物料排产；销售订单生成一张多产出生产订单；每个产出行锁定 BOM 版本并关联一组理论用料。 |
| 批次库存 | 手工收货、批次、生产日期、到期日期、库存余额和库存事务；按物料规则展示临期/过期提醒基础数据。 |
| 技术运行 | NestJS + Prisma + PostgreSQL API、React + Vite Web；PostgreSQL 与 Redis 组合基础镜像；本地持久化；桌面和移动端基础响应式布局。 |

## 4. 尚未实现的一期能力

- 图片 OCR 字段自动识别：当前图片文件安全保存并生成待人工确认任务；未配置 OCR 服务时不伪造识别结果。
- 生产报废目前以库存报废作业记录，工单级报废明细和损耗原因仍可增强。
- 月结与库存金额对账已有数据基础，正式关账流程仍需结合财务上线方案确认。
- 附件删除/生命周期清理、导入错误行下载和幂等请求专用查询仍可增强。
- 成本、库存和经营报表已提供基础查询，钻取、导出和订阅仍可增强。
- 关键领域单元测试、API 冒烟和正式 Prisma 基线迁移已加入；完整跨单据端到端回归、备份恢复演练仍需上线前执行。

## 5. 上线前优先级

### P0：验收与安全

1. 在隔离验收库执行采购、生产、销售、退货和冲销的完整跨单据回归。
2. 完成备份、恢复和故障回滚演练。
3. 配置正式密钥、口令、HTTPS、监控和告警。

### P1：录入效率与运营增强

1. 接入选定的图片 OCR 服务并基于真实单据版式调优字段置信度。
2. 增加导入错误行下载、报表钻取/导出和附件生命周期管理。
3. 增加采购/销售草稿整单编辑、自动库存预留和工单级报废明细页。

### P2：后续扩展

1. 扩展多仓、部门数据范围和更细粒度的业务对象权限。
2. 增加通知、报表订阅和摄像头扫码优化。
3. 结合财务方案完善月结、账龄和库存金额对账流程。

## 6. 当前验收结论

当前版本已形成采购收货、生产领退料/完工、销售批次发货、库存作业、移动平均成本、批次追溯、XLSX 草稿导入和基础报表闭环，适合在测试环境进行一期业务验收。上线前仍需完成图片 OCR 服务接入、完整跨单据端到端回归、数据范围权限和备份恢复演练。
