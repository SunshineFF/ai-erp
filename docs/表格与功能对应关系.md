# ERP 表格与功能对应关系

> 用途：一期系统的页面、业务功能、API 和数据库表速查。本文按当前代码实现维护，字段详情以 `docs/04-一期数据库表设计.md` 和 `apps/api/prisma/schema.prisma` 为准。

## 1. 使用约定

- 页面列表默认按业务记录 `id` 倒序；列表展示业务编号、名称或日期，不展示内部 `id`。
- 页面之间通过名称、单号、批次号等可读字段建立操作路径；`id` 仅用于接口和内部关联。
- 删除按钮必须先通过二次确认。删除执行物理删除；属于父记录的草稿明细可安全级联，订单、库存、生产、财务、审计等历史引用存在时返回 `409 DELETE_CONFLICT` 并拒绝删除。
- 有关联数据的操作会提示影响范围，并说明历史记录可从对应业务列表或“查询报表”查看。
- 删除请求遇到外键冲突时，API 返回依赖资源、数量和处理建议；前端在当前页面显示明显错误，不会把删除降级为软停用。
- 金额、数量和汇率使用高精度数值；财务支出通过“真实金额”为负数参与汇总。

## 3. 数据表与功能对应

### 3.1 平台、认证和权限

| 表 | 保存内容 | 被哪些功能使用 | 关联关系 |
| --- | --- | --- | --- |
| `companies` | 公司、基准币种、启用状态 | 登录上下文、所有业务隔离 | 一对多关联用户、财务和业务数据 |
| `users` | 用户名、密码哈希、姓名、企业微信成员 ID、状态 | 账号登录、企业微信登录、出库人、审计 | `user_roles`；出库单可关联出库人 |
| `roles` | 角色编码、名称、系统角色、状态 | 用户与权限 | `user_roles`、`role_permissions` |
| `permissions` | 模块、动作权限 | 菜单显示和 API 鉴权 | 被角色授权 |
| `user_roles` | 用户-角色-公司关系 | 登录后权限计算 | 联合唯一 `userId + roleId + companyId` |
| `role_permissions` | 角色-权限关系 | 菜单和接口权限 | 联合唯一 `roleId + permissionId` |
| `audit_logs` | 操作者、资源、前后数据、请求信息 | 关键操作审计 | 通过 `resourceType + resourceId` 追溯 |

### 3.2 基础主数据

| 表 | 保存内容 | 业务用途 | 典型操作路径 |
| --- | --- | --- | --- |
| `currencies` | 币种、符号、小数位、本位币、状态 | 订单、流水、报销 | 设置 → 币种 |
| `exchange_rates` | 币种每日兑 CNY 汇率 | 外币订单金额换算 | 设置 → 汇率 |
| `tax_rates` | 税率和生效区间 | 订单含税金额、税额快照 | 设置 → 税率 |
| `units` | 单位和精度 | 物料、订单、库存数量 | 设置 → 单位 |
| `unit_conversions` | 物料单位换算因子 | 不同单位录入/换算 | 设置 → 单位换算（接口支持） |
| `material_categories` | 物料分类 | 物料分类筛选 | 设置 → 物料分类 |
| `warehouses` | 仓库 | 库存组织 | 设置 → 仓库 |
| `locations` | 库位和类型 | 收货、领料、出库、生产入库 | 设置 → 库位 |
| `materials` | 编码、名称、规格、图片、类型、单位、效期和业务属性 | 采购、销售、BOM、生产、库存的共同主数据 | 物料主数据 → 新增/编辑/停用 |
| `suppliers` | 供应商编码、名称、联系人、币种、状态 | 采购订单、应付账单 | 供应商 → 新增/停用 → 采购订单 |
| `customers` | 客户编码、名称、联系人、币种、状态 | 销售订单、出库单、应收账单 | 客户 → 新增/停用 → 销售订单/出库单 |

### 3.3 采购、销售和出库

| 表 | 保存内容 | 关联表 | 业务规则 |
| --- | --- | --- | --- |
| `purchase_orders` | 采购单号、供应商、日期、状态、币种、金额汇总 | `purchase_order_lines`、`suppliers` | 列表支持供应商和创建日期时间段筛选 |
| `purchase_order_lines` | 物料、数量、收货/退货数量、单位、单价、批次和金额快照 | `materials`、`inventory_batches` | 收货累计更新 `receivedQty` |
| `sales_orders` | 销售单号、客户、日期、状态、币种、金额汇总 | `sales_order_lines`、`customers`、`sales_shipments` | 列表支持客户和创建日期时间段筛选 |
| `sales_order_lines` | 物料、销售数量、已出库/退货数量、价格和金额快照 | `materials`、`sales_shipment_lines` | 出库累计不得超过销售数量 |
| `sales_shipments` | 出库单号、销售单、客户、出库人、出库时间、累计金额 | `sales_shipment_lines`、`users`、`customers` | 同一销售单可多次出库；出库总数必须等于销售数量 |
| `sales_shipment_lines` | 销售行、批次、库位、数量、单价、行金额、退货数量 | `sales_orders`、`inventory_batches` | 一行可选择一个库存批次，支持多行明细 |
| `bills` | 应收/应付账单、来源单据、日期、金额、状态 | `purchase_orders`、`sales_orders`、`customers`、`suppliers` | 财务 → 对账/账单；可由订单批量生成 |

### 3.4 BOM、生产和库存

| 表 | 保存内容 | 关联表 | 业务用途 |
| --- | --- | --- | --- |
| `boms` | 成品、版本、状态、标准产量、有效期、保密等级 | `bom_items`、`materials` | 生产下达前锁定 BOM 版本 |
| `bom_items` | 投入物料、标准用量、单位、损耗率 | `boms`、`materials` | 生产理论用料展开 |
| `production_orders` | 生产单号、类型、产出摘要、BOM 快照、计划/完工/报废量、状态 | `production_output_lines`、`production_materials`、销售订单 | 支持按库存或按销售订单生产；完成判定 = 完工 + 报废 达到计划量 |
| `production_output_lines` | 多产出物料行、BOM 快照、计划/完工/报废量 | `production_orders`、`production_materials` | 生产订单多行产出 |
| `production_materials` | 理论用料、已领料、已退料、损耗率 | `production_orders`、产出行、`materials` | 领料/退料数量控制 |
| `inventory_batches` | 物料批次、生产/到期日期、批次状态、来源和单位成本 | `materials`、库存事务 | FEFO、临期预警、批次追溯 |
| `inventory_balances` | 仓库/库位/物料/批次的现存、预留、可用数量 | `inventory_batches`、`materials` | 列表库存和出库可用量读取 |
| `inventory_transactions` | 每一笔库存数量和成本变化、来源单据、冲销关系 | 各业务单据、批次、成本 | 库存事实账，不直接编辑数量 |
| `inventory_documents` | 收货、领料、发货、盘点、调整等库存单据 | `inventory_document_lines` | 现场作业单据载体 |
| `inventory_document_lines` | 库存单据的批次、库位、数量明细 | `inventory_documents` | 过账前后的明细记录 |
| `material_costs` | 当前库存量、库存金额、移动平均成本 | `materials`、`cost_records` | 工作台和库存金额汇总 |
| `cost_records` | 每笔库存事务的成本变化和余额快照 | `inventory_transactions` | 成本追溯和报表 |
| `batch_genealogy` | 成品批次与原料批次消耗关系 | 生产订单、输入/输出批次 | 正向/反向批次追溯 |

### 3.5 财务、附件和导入

| 表 | 保存内容 | 业务用途 | 特别规则 |
| --- | --- | --- | --- |
| `cash_flows` | 现金收入/支出、金额、真实金额、日期、描述、来源单据 | 财务 → 现金流水 | 支出真实金额为负数；同一时间同一金额只允许一笔 |
| `reimbursements` | 报销单号、日期、币种、说明、报销合计 | 财务 → 费用报销 | 一张报销单包含多笔费用 |
| `reimbursement_items` | 费用类型、金额、说明 | 报销明细和报销合计 | 可上传多个支付凭证 |
| `reimbursement_attachments` | 文件名、媒体地址、MIME、大小 | 支付凭证查看 | 默认本地媒体目录；可配置阿里云 OSS/CDN |
| `document_files` | 导入原始文件和受控下载信息 | 文件导入、审计 | 原件不直接暴露存储路径 |
| `import_tasks` | 导入任务、文件、状态、错误信息 | 文件导入复核 | 解析后先复核，再写入业务表 |
| `import_task_items` | 导入行、解析结果、错误和目标对象 | 导入预览/纠错 | 用于逐行显示导入结果 |

## 5. 典型业务操作路径

### 5.1 采购入库

1. 设置 → 单位/分类/仓库/库位 → 物料主数据 → 新增物料。
2. 供应商 → 新增供应商。
3. 采购订单 → 新增采购订单 → 选择供应商、日期和物料明细 → 保存。
4. 采购订单 → 确认 → 收货入库，录入批次、库位、数量和成本。
5. 批次库存查看 `inventory_batches`、`inventory_balances`；财务可由采购订单生成应付账单。

### 5.2 销售出库

1. 客户 → 新增客户。
2. 销售订单 → 新增销售订单 → 选择客户、日期和物料数量 → 确认。
3. 销售订单 → “创建出库单”或进入出库单页面。
4. 出库单选择出库人、客户、销售单、批次和库位，支持分批出库。
5. 系统校验累计出库数量不超过销售数量；出库完成后生成库存事务和应收账单来源。

### 5.3 生产闭环

1. 物料主数据维护可生产成品及单位。
2. 配方 BOM → 新增投料明细 → 发布。
3. 生产订单 → 新增订单（可关联销售订单）→ 系统展开理论用料。
4. 下达生产订单 → 现场作业领料/退料 → 完工入库（可同时申报报废数量，默认 0，可手动修改；报废不入库，实际完成数 = 完工数量；累计完工 + 累计报废 = 计划数量时生产单自动完成）。
5. 通过批次库存、成本记录和批次追溯查看实际影响。

### 5.4 财务报销与流水

1. 财务 → 费用报销 → 新增报销。
2. 一张报销单添加多笔费用，每笔费用上传一个或多个支付凭证。
3. 保存后，报销单和费用明细写入 `reimbursements` / `reimbursement_items`，凭证写入媒体存储。
4. 报销对应的现金流水可在财务 → 现金流水展开查看；流水详情可回到报销单。
5. 财务 → 现金流水支持模板下载和表格导入；导入前复核，同一时间同一金额重复记录会被拒绝。

## 6. 删除、停用和关联数据提示

| 对象 | 实际动作 | 历史数据 | 用户提示重点 |
| --- | --- | --- | --- |
| 物料、供应商、客户、设置字典 | 物理删除；有引用时拒绝 | 被引用记录保留 | 删除前二次确认；冲突时显示引用资源及处理建议 |
| BOM | 物理删除 BOM 及其明细；有生产或审计引用时拒绝 | 已生成生产订单和耗料记录保留 | 已被使用的 BOM 不允许删除 |
| 生产订单 | 仅草稿可删除 | 已过账单据不删除 | 删除草稿会移除未过账计划；关联销售和库存历史不受影响 |
| 用户/角色 | 物理删除授权关系与对象；受保护对象拒绝 | 审计记录保留 | 当前用户、系统角色或存在审计/用户授权时禁止删除 |
| 表单明细行 | 仅从当前表单移除 | 尚未保存内容丢失 | 必须确认，明确数量、价格、批次、凭证等填写内容将丢失 |
| 支付凭证 | 删除附件 | 该附件不再可访问 | Web/移动端均需确认具体文件；报销金额和报销单本身不删除 |
| 报销单 | 物理删除 | 报销明细、支付凭证和自动生成的现金流水一并删除 | 删除前明确提示级联影响；若要保留财务历史，应改为保留报销单而不删除 |
| 出库单 | 冲销后物理删除 | 销售行已出库数量回退；库存原始事务和冲销记录保留 | 仍有未冲销库存事务时禁止删除，先到现场作业逐笔冲销 |
